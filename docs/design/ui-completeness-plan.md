## 1. 배경

마법·적 콘텐츠를 동결하고 개발 축을 완성도로 옮기는 방향 전환(로드맵 v0.3)의 첫 영역으로 **UI**를 잡았다. 이 문서는 두 가지를 한다 — 지금 게임에 실제로 구현된 UI를 감사하고, 호드 서바이벌 장르(뱀파이어 서바이버즈·Brotato·Magic Survival·20 Minutes Till Dawn)에서 범용적으로 쓰는 UI 요소와 견줘 무엇이 비어 있는지 리스트로 만든다.

이 문서는 "무엇을 만들지"(요소·화면의 목록과 우선순위)를 다룬다. "어떻게 보일지"(폰트·색·간격·모션 등 비주얼 디자인 시스템)는 다음 단계에서 `/design-consultation`으로 별도로 잡는다.

## 2. 현재 UI 감사 (실제 구현된 것)

씬 세 개(`menu` / `main` / `result`)와 UI 컨트롤러 다섯 개(`MainMenuController`·`HudController`·`ResultController`·`CardSelectPanel`·`LocalizedLabel`)가 정본이다.

| 화면 | 구현된 것 | 상태 |
|---|---|---|
| 메인 메뉴 (`menu.scene`) | 타이틀 "MONSTER" + PLAY 버튼 하나 | 최소 골격 |
| 인게임 HUD (`main.scene`) | HP(텍스트)·웨이브 번호·타이머(20분 카운트다운)·레벨·XP(텍스트) | 텍스트 라벨만 |
| 레벨업 카드 (오버레이) | 카드 3장(이름 + 설명 텍스트), 선택 시 적용·재개 | 아이콘·등급·리롤 없음 |
| 게임오버 (오버레이) | "GAME OVER" + RESTART + MENU | 런 통계 없음 |
| 결과 화면 (`result.scene`) | 승/패 + 도달 웨이브 + RETRY + MENU | 웨이브 숫자뿐 |

게임 상태(`GameState`)는 `Playing`·`LevelUp`·`GameOver` 세 가지뿐이고 **수동 일시정지 상태가 없다.** i18n 카탈로그(`ko.json`/`en.json`)의 UI 텍스트도 위 화면들(`menu.*`·`hud.*`·`card.*`·`result.*`·`gameover.*`)에 한정된다.

## 4. v1 완성도 UI 우선순위 리스트 (초안)

동결 방침(신규 콘텐츠 없음, 완성도 위주)에 맞춰 우선순위를 매겼다.

### P0 — 코어 루프 완성감 (없으면 미완성으로 보이는 것)

1. **HP 바 + XP 바** — 텍스트를 시각 바로 승격. 저비용에 체감이 크다.
2. **보유 마법 아이콘 행** — 자기 빌드를 눈으로 보게 한다. (아이콘 아트에 의존 → placeholder로 시작.)
3. **일시정지 메뉴** — ESC로 열고 Resume·재시작·메뉴·설정. 게임 상태에 `Paused`를 신설한다.
4. **결과 화면 런 통계** — 생존 시간·레벨·킬 수·획득 마법 등. 현재 웨이브 숫자만 있는 큰 공백을 채운다.
5. **레벨업 카드 폴리시** — 등급색·아이콘·스킵 옵션. 백로그 I3(정지 발사체가 카드 가림) 레이어 버그도 함께.

### P1 — 메타 완성 (로드맵 §7 요구)

6. **설정 화면** — 볼륨(마스터·BGM·SFX)과 언어 토글. i18n 틀을 재사용한다.
7. **메인 메뉴 확장** — 도감·설정 진입 추가.
8. **도감** — 적 12종 + 마법 5종의 해금 표시.
9. **세이브** — localStorage에 클리어 수·도감·설정 저장.

### P2 — juice / 폴리시 (후반 폴리시 구간)

10. 데미지 숫자, 킬 카운터, 씬 전환, 토스트 알림, 튜토리얼 힌트.

### 범위 밖 (v2 / 이월)

- 캐릭터 선택, 도전과제(Steamworks), 보스 HP 바, 미니맵.

## 5. 리스트를 확정하는 두 갈림길

아래 두 결정이 필요한 화면 수를 크게 가른다.

- **메타 진행(해금) 모델** — 최소(클리어 수 + 도감 해금)로 가면 상점·재화·영구 강화 화면이 필요 없어 UI 부담이 가장 가볍다. 뱀서식 영구 강화 상점으로 가면 상점 화면 + 골드 HUD + 런 사이 재화 시스템이 붙어 UI·로직이 상당히 커진다.
- **아이콘 아트 의존 시점** — 로드맵은 아트를 7-9주차로 미룬다. placeholder(단색 박스·기본 도형)로 UI 배치와 로직을 먼저 완성하고 최종 아이콘은 아트 단계에 교체하면, 구조와 아트를 분리해 순서 꼬임을 막는다.

## 6. 채택한 스코프 기본값 (사용자 확인 대기)

사용자 부재(2026-07-02) 상황에서 저위험 기본값을 채택했다. 돌아와서 조정 가능하다.

- **메타 진행 → 최소(클리어 수 + 도감 해금).** 동결 방침과 정합하고 UI 부담이 가볍다. 영구 강화 상점·골드 HUD·재화 시스템은 채택하지 않는다(필요하면 v2).
- **아이콘 아트 → placeholder로 구조 먼저.** 아이콘 의존 UI(마법 행·도감)도 단색·도형 placeholder로 배치·로직을 완성하고, 최종 아이콘은 아트 단계에 교체한다.

이 두 기본값 위에서 위 P0~P2 리스트가 성립한다. 메타 모델을 상점형으로 바꾸면 E영역과 결과 화면 보상·골드 HUD가 크게 늘어난다.
