# 디자인 정본 (spec)

> 이 폴더에 무엇이 있고 어떤 이름으로 두나

이 폴더의 문서는 전부 **정본**이다. "지금 어떻게 되어 있나"에 답하고, 낡으면 새로 만들지 않고 그 문서를 고친다. 결정 기록(`../../development/sessions/`·`../../decisions/`)으로 나가는 링크를 걸지 않는다 — 링크를 타고 들어간 사람이 폐기된 명세를 현재 명세로 읽은 사고가 실제로 있었다(2026-08-08).

`docs/design/` 바로 아래와 갈리는 기준은 **정본이냐 초안이냐**다. 초안(`*-draft.md`)과 진행 중 계획은 그대로 위에 둔다.

새 정본은 `pnpm wf canon <분류>-<주제> "<제목>" "<답하는 질문>" --design`으로 만든다.

## 분류 접두사 — 닫힌 집합

| 접두사 | 범위 |
|---|---|
| `art-` | 아트 — 방향, 사양, 생성 절차 |
| `ui-` | UI·UX — 화면 흐름, 레이아웃 규약 |

**늘리려면 이 표를 먼저 고친다.** `wf canon`이 이 집합 밖의 접두사를 거부한다.
