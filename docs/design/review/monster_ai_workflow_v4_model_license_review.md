# monster 프로젝트 AI 아트 제작 워크플로우 재검토 문서 v4

## 목적

이 문서는 기존 monster 프로젝트의 AI 이미지 제작 방식에서 발생한 문제를
분석하고, 새로운 로컬 AI 기반 캐릭터 제작 파이프라인을 검토하기 위한
문서이다.

검토 목적:

-   플레이어 캐릭터 4방향 Body Master 제작
-   동일 캐릭터 유지
-   파츠 기반 스킨 시스템 제작
-   유료 스킨/디자인 판매 가능성 검토
-   사용할 AI 모델 및 라이선스 검토
-   Claude Code 추가 검토용 기준 제공

------------------------------------------------------------------------

# 1. 기존 워크플로우 분석

## 기존 구성

    ComfyUI
    +
    SDXL 1.0 Base
    +
    f58_anime_style LoRA
    +
    프롬프트 기반 생성

초기 단계:

-   컨셉 이미지 생성
-   화풍 결정
-   캐릭터 후보 제작

목적으로는 정상적으로 동작했다.

하지만 플레이어 4방향 제작 단계에서 문제가 발생했다.

------------------------------------------------------------------------

# 2. 확인된 핵심 문제

## 2.1 시점과 캐릭터 동일성 충돌

실측 결과:

-   스타일 LoRA 강도를 높이면 캐릭터 동일성 증가

-   하지만 Back / Side View 생성 실패

-   스타일 LoRA 강도를 낮추면 방향 변화 가능

-   하지만 캐릭터 동일성 붕괴

결론:

스타일 LoRA는 캐릭터 방향 제어 기술이 아니다.

------------------------------------------------------------------------

## 2.2 SDXL Base의 한계

SDXL Base는:

강점:

-   고품질 일러스트
-   색감
-   분위기
-   일반 캐릭터 디자인

약점:

-   정확한 Back View
-   완전 측면
-   동일 캐릭터 4방향 유지

문제는 프롬프트가 아니라 모델 구조와 제어 방식이다.

------------------------------------------------------------------------

## 2.3 원본 데이터 문제

기존 캐릭터는:

-   로브
-   망토
-   장식
-   가려진 신체 영역

이 존재했다.

가려진 신체는 AI가 정확한 구조를 보유하고 있는 것이 아니다.

따라서:

"가려진 부분을 편집으로 복구"

하는 방식은 한계가 있다.

------------------------------------------------------------------------

# 3. 새로운 방향

## 기존

    완성 캐릭터 생성
            ↓
    4방향 생성

## 변경

    Body Master 제작
            ↓

            ↓
    의상 / 헤어 / 무기 제작
            ↓
    게임 엔진 조합

------------------------------------------------------------------------

# 4. Body Master 정의

Body Master는 완성 일러스트가 아니다.

목적:

모든 스킨과 장비의 기준이 되는 신체 베이스.

포함:

-   얼굴 기준
-   두상
-   피부
-   팔
-   손
-   다리
-   발
-   기본 포즈

제외:

-   복잡한 의상
-   무기
-   장식
-   과도한 가림

------------------------------------------------------------------------

# 5. 추천 AI 제어 기술

## ControlNet

역할:

AI 생성 결과에 구조 정보를 제공.

사용:

-   포즈 유지
-   형태 유지
-   방향 제어

------------------------------------------------------------------------

## OpenPose

역할:

인체 관절 구조 제어.

관리:

-   머리
-   어깨
-   팔꿈치
-   손
-   무릎
-   발

4방향 제작에서 핵심.

------------------------------------------------------------------------

## IP-Adapter

역할:

캐릭터 정체성 유지.

질문:

"같은 캐릭터인가?"

를 담당.

------------------------------------------------------------------------

## Lineart

역할:

외곽선 유지.

------------------------------------------------------------------------

## Depth

역할:

앞뒤 구조 유지.

------------------------------------------------------------------------

## Inpainting

역할:

부분 수정.

예:

-   손만 수정
-   팔만 수정
-   특정 영역만 수정

전체 재생성을 피한다.

------------------------------------------------------------------------

## LoRA

역할:

특정 캐릭터/스타일 학습.

주의:

Body Master 확정 이후 사용하는 것이 적합.

------------------------------------------------------------------------
