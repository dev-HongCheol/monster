# monster 플레이어 캐릭터 아트 파이프라인 — 최종 기준 문서

> **문서 목적**
>
> 2D 탑다운 액션 로그라이크 「monster」의 플레이어 캐릭터를  
> **스킨/장비 교체가 가능한 2D 스켈레탈 캐릭터**로 제작하기 위한 최종 아트 생성 기준을 정의한다.
>
> **핵심 전제:** 현재 확정된 1단계 정면 초안(Base Character Master)은 완성된 정본이며, 이후 단계에서는 이 캐릭터의 정체성·비율·크기·각도를 다시 설계하지 않는다.

---

## 1. 최종 목표

최종적으로 다음 구조의 캐릭터를 만든다.

```text
[Base Character Master]
        │
        ├── 4방향 기본 캐릭터
        │    ├── Front
        │    ├── Back
        │    ├── Left 3/4
        │    └── Right 3/4
        │
        ├── Hair 4방향
        ├── Upper Clothing 4방향
        ├── Lower Clothing 4방향
        ├── Gloves 4방향
        ├── Boots 4방향
        └── Staff / Weapon 4방향
                 │
                 ▼
          배경 제거 / 정렬
                 │
                 ▼
          Spine Essential 리깅
                 │
                 ▼
       v2 스킨 / 장비 교체 시스템
```

최종 목적은 단순히 예쁜 캐릭터 일러스트를 만드는 것이 아니다.

**하나의 동일한 캐릭터를 여러 파츠로 분리하고, 각 파츠를 독립적으로 교체할 수 있는 구조**를 만드는 것이 최우선이다.

---

# 2. 절대 기준 — Base Character Master

현재 확정된 정면 초안을 모든 후속 생성의 **유일한 캐릭터 기준 이미지**로 사용한다.

이후 생성에서 다음 항목은 변경하지 않는다.

- 얼굴
- 얼굴형
- 눈
- 코
- 입
- 헤어가 없는 상태에서의 두상 기준
- 캐릭터의 전체 체형
- 머리 크기
- 4등신 비율
- 다리 길이
- 다리 굵기
- 골반 폭
- 몸통 비율
- 팔 길이와 굵기
- 손 크기와 형태
- 발 크기
- 전체 캐릭터 높이
- 전체 캐릭터 폭의 기준
- 기본 포즈
- 기본 색상
- 캐릭터의 젊은 여성형 실루엣

### 2.1 체형 기준

캐릭터는 **4등신 치비/SD 체형**이다.

- 사실적인 인체 비율 금지
- 5~6등신 이상의 비율 금지
- 지나치게 아기 인형처럼 둥글고 통통한 체형 금지
- 머리는 크지만 과도하게 비대하지 않음
- 다리는 짧지만 지나치게 굵지 않음
- 골반은 넓고 둥근 아기형이 아니라 슬림한 치비 여성형
- 다리 길이는 4등신 체형 안에서 충분히 읽히도록 확보
- 전체적으로 귀엽지만 어린아이 체형이 아닌 **젊은 여성 마법사**의 실루엣

---

# 3. 캐릭터 정의

캐릭터의 기본 설명은 다음 문장을 기준으로 한다.

```text
young woman fire mage, long scarlet hair, amber eyes, fair and pale skin,
short tunic with short sleeves in bright cream orange, pants in dark brown,
ankle boots in medium leather brown, fingerless gloves in dark brick red,
plain wooden staff without ornament
```

이 문장은 캐릭터 동일성 유지를 위해 가능한 한 그대로 사용한다.

# 4. 파츠 시스템의 핵심 원칙

## 4.1 가림 최소화

**갈아 끼울 파츠가 아래 파츠를 가리지 않게 한다.**

가려진 영역은 원본에 존재하지 않을 수 있으므로, 이후 파츠 교체 시 구멍이 생길 수 있다.

따라서 다음을 기본 원칙으로 한다.

- 머리카락은 어깨와 상의를 과도하게 가리지 않는다.
- 팔과 몸통의 경계를 확인할 수 있어야 한다.
- 양팔은 가능한 한 독립적으로 읽혀야 한다.
- 손은 다른 손과 붙지 않는다.
- 손은 몸통이나 옷에 과도하게 가려지지 않는다.
- 상의는 하의를 불필요하게 가리지 않는다.
- 하의는 허리와 벨트 영역까지 온전히 존재한다.
- 신발은 하의를 가리지 않는 명확한 경계를 가진다.
- 지팡이는 몸통을 가로지르지 않는다.
- 무기와 손은 분리 가능한 구조로 유지한다.

## 4.2 같은 시트 안에 존재하는 정보는 재활용 가능

모든 가림이 반드시 별도의 생성 시트를 요구하는 것은 아니다.

정면/뒷면 등 다른 패널에서 해당 부위가 온전히 존재하고, 편집으로 안정적으로 재구성할 수 있다면 재활용할 수 있다.

반대로 시트 어디에도 존재하지 않는 영역은 별도의 베이스/변형 작업이 필요하다.

---

# 5. 기본 신체 베이스

최종 시스템의 가장 중요한 개념은 **몸 자체가 가장 아래에 있는 공통 베이스**라는 것이다.

권장 구조:

```text
Layer 0
  뒷머리

Layer 1
  머리/얼굴
  몸통 피부
  양팔 피부
  양손
  양다리 피부
  발

Layer 2
  하의
  벨트 포함

Layer 3
  상의
  소매

Layer 4
  장갑
  신발

Layer 5
  무기

Layer 6
  앞머리 / 옆머리
```

실제 게임에서 필요한 장비가 추가되면 이 구조를 확장한다.

# 6. 의상 기준

## 6.1 상의

기본 상의는 짧은 튜닉이다.

- 허리선에서 끝난다.
- 벨트 바로 위에서 끝난다.
- 엉덩이까지 내려오지 않는다.
- 바지를 덮지 않는다.
- 크롭탑처럼 배가 넓게 노출되는 형태가 아니다.
- 소매는 짧다.
- 팔의 아래쪽은 맨살 기준이 존재해야 한다.

## 6.2 하의

- 허리부터 부츠 바로 위까지 이어지는 긴 바지
- 7부/카프리 형태 금지
- 종아리를 불필요하게 노출하지 않는다.
- 부츠와 명확하게 경계가 생긴다.
- 벨트까지 하의가 완전히 존재한다.

## 6.3 신발

- ankle boots
- 발목 바로 위에서 끝난다.
- 종아리까지 올라오는 장화 형태 금지

## 6.4 장갑

- fingerless gloves
- 손가락이 장갑 밖으로 나온다.
- 손가락은 서로 과도하게 벌어지지 않는다.
- 작은 화면에서 하나의 덩어리로 읽힌다.

---

# 7. 손과 무기

## 7.1 지팡이 손

지팡이를 쥔 손은 **relaxed half-grip**이다.

- 완전한 주먹 금지
- 완전히 편 손 금지
- 손 안쪽에 무기 손잡이가 지나갈 수 있는 명확한 공간이 있다.
- 손과 지팡이는 독립 파츠로 취급한다.

## 7.2 빈 손

빈 손은 약간 오므린 relaxed hand이다.

- 활짝 편 손 금지
- 완전한 주먹 금지
- 손가락이 서로 지나치게 분리되지 않는다.
- 이후 방패/책 등의 장비를 추가할 수 있는 베이스가 된다.

## 7.3 무기

기본 지팡이:

```text
plain wooden staff without ornament
```

- 장식 없음
- 발광 없음
- 불꽃 없음
- 파티클 없음
- 손과 하나의 이미지로 굽지 않는다.
- 별도 무기 파츠로 생성/관리한다.

---

# 8. 4방향 생성 기준

Base Character Master가 확정된 이후 4방향을 만든다.

## 8.1 뷰

```text
Front
Back
Left 3/4
Right 3/4
```

측면은 완전한 90도 옆모습이 아니라 **약간 앞을 향한 3/4 측면**으로 한다.

이는 탑다운 게임에서 방향 차이를 명확하게 표현하기 위한 의도적인 선택이다.

## 8.2 공통 조건

네 방향 모두 다음을 동일하게 유지한다.

- 동일 캐릭터
- 동일 머리 크기
- 동일 4등신 비율
- 동일 전체 캐릭터 높이
- 동일 체형
- 동일 다리 길이
- 동일 다리 굵기
- 동일 골반 비율
- 동일 팔/손 비율
- 동일 발 크기
- 동일 포즈 계열
- 동일 색상
- 동일 의상
- 동일 지팡이
- 동일 배경
- 동일 캐릭터 세로 크기
- 동일 발 밑선

## 8.3 금지

- 3/4 정면을 임의로 정면으로 바꾸기
- 뒷모습에서 얼굴을 보여주기
- 상체와 하체의 방향 불일치
- 네 방향에서 지팡이 손 변경
- 팔 하나 생략
- 지팡이 위치 변경으로 몸통 가리기
- 방향마다 캐릭터 크기 변경
- 방향마다 체형 변경
- 좌우 반전만으로 측면을 대체

---

# 9. 파츠별 4방향 생성

4방향 기본 캐릭터가 확정된 뒤, 각 파츠를 별도로 생성한다.

기본 대상:

```text
1. Base Body
2. Hair
3. Upper Clothing
4. Lower Clothing
5. Gloves
6. Boots
7. Staff / Weapon
```

각 파츠는 해당 방향의 Base Character와 정확히 같은:

- 크기
- 위치
- 회전
- 각도
- 발 밑선
- 관절 위치
- 파츠 기준점

을 유지해야 한다.

## 9.1 가장 중요한 규칙

**파츠를 새 캐릭터처럼 다시 디자인하지 않는다.**

항상:

> Base Character Master → 해당 방향 → 해당 파츠

라는 관계를 유지한다.

파츠 생성에서 캐릭터의 체형이나 얼굴을 개선하려 하지 않는다.

---

# 10. 머리카락

헤어는 독립 파츠다.

목표:

- 머리/얼굴을 가리지 않는다.
- 어깨와 소매를 과도하게 덮지 않는다.
- 어깨 관절과 팔 연결부를 가리지 않는다.
- 옷 파츠의 상단 영역을 가능한 한 보존한다.
- 뒷머리와 앞/옆머리를 필요에 따라 별도 레이어로 분리할 수 있다.

헤어 생성 시 가장 중요한 기준은 **예쁜 머리보다 몸과 옷의 파츠 분리가 가능한가**이다.

---

# 11. 변형 베이스

필요한 경우 기본 캐릭터와 동일한 포즈/비율/크기의 변형 베이스를 만든다.

## 11.1 Hair-Off Base

머리카락을 제거하고:

- 두피
- 목
- 어깨
- 윗가슴
- 윗등

을 완전히 노출한다.

머리 크기와 얼굴은 Base Master와 동일하게 유지한다.

## 11.2 Clothing-Off Base

옷을 제거하여:

- 어깨
- 가슴
- 몸통
- 허리
- 골반
- 양팔
- 양손
- 양다리
- 발

을 온전히 확보한다.

특히 어깨와 팔의 경계가 명확해야 한다.

# 12. 생성 이미지의 공통 출력 규칙

모든 생성 단계에서 다음을 유지한다.

### 배경

- 단색 평평한 회색
- 완전히 균일한 밝기
- 그라데이션 없음
- 질감 없음
- 얼룩 없음
- 비네팅 없음
- 모서리 어두워짐 없음

### 효과

금지:

- 불꽃
- 발광
- 글로우
- 파티클
- 마법 효과
- 바닥 그림자
- 지면 선

이펙트는 게임 런타임에서 별도로 처리한다.

### 기타

금지:

- 두 번째 무기
- 두 번째 캐릭터
- 방패
- 책
- 장신구
- 모자
- 후드
- 머리띠
- 텍스트
- 워터마크
- 프레임
- 테두리

# 13. 화풍

- anime cel shading
- 서구 하이판타지 색감과 형태
- 미형 얼굴
- 큰 눈
- 작은 코
- 작은 입

- 단순하고 읽기 쉬운 큰 형태

작은 화면에서 표시되므로 세밀한 장식보다 **큰 실루엣과 명확한 파츠 경계**를 우선한다.

# 14. 생성 후 최종 검수

현재 Base Character Master가 완벽하다는 전제라면, 다음 단계로 넘어가기 전에 확인할 것은 **디자인 개선이 아니라 기준 고정**이다.

## 14.1 Base Master 고정 체크

- [ ] 4등신 체형
- [ ] 머리 크기 확정
- [ ] 이마/얼굴 비율 확정
- [ ] 다리 길이 확정
- [ ] 다리 굵기 확정
- [ ] 골반 폭 확정
- [ ] 젊은 여성형 치비 실루엣
- [ ] 얼굴 정체성 확정
- [ ] 손 모양 확정
- [ ] 지팡이 손의 half-grip 확정
- [ ] 빈 손의 relaxed curl 확정
- [ ] 상의 길이 확정
- [ ] 하의 길이 확정
- [ ] 부츠 길이 확정
- [ ] 장갑 형태 확정
- [ ] 캐릭터 전체 크기/위치 확정
- [ ] 배경 규격 확정

**이 체크를 통과한 이미지는 이후 체형 수정의 기준이 된다.**

# 15. 4방향 검수 기준

4방향이 만들어진 뒤에는 다음을 비교한다.

### 캐릭터 동일성

- [ ] 얼굴/두상 동일성
- [ ] 머리 크기 동일
- [ ] 4등신 비율 동일
- [ ] 몸통 비율 동일
- [ ] 골반 비율 동일
- [ ] 다리 길이 동일
- [ ] 다리 굵기 동일
- [ ] 발 크기 동일

### 기하학

- [ ] 네 뷰의 발 밑선 동일
- [ ] 캐릭터 세로 크기 동일
- [ ] 머리 위치 일관
- [ ] 몸통 위치 일관
- [ ] 팔/손 관절 위치 일관
- [ ] 지팡이 손 동일
- [ ] 지팡이 위치 일관

### 해부학

- [ ] 팔 두 개 존재
- [ ] 손 두 개 존재
- [ ] 다리 두 개 존재
- [ ] 상체/하체 방향 일치
- [ ] 뒷모습에서 얼굴이 보이지 않음
- [ ] 측면에서도 의도한 3/4 방향 유지

---

# 16. 파츠 생성 검수

각 파츠는 생성 직후 다음을 확인한다.

- [ ] 원본 캐릭터와 동일한 크기
- [ ] 동일한 위치
- [ ] 동일한 각도
- [ ] 동일한 관절 위치
- [ ] 다른 파츠를 가려야 할 영역이 불필요하게 포함되지 않음
- [ ] 필요한 아래층이 충분히 존재함
- [ ] 파츠 경계가 명확함
- [ ] 파츠가 캐릭터의 다른 부위를 새로 덮어버리지 않음

---

# 17. 배경 제거 및 출하

생성물은 회색 배경 상태로 보관하고, 최종 사용 단계에서 투명 PNG로 변환한다.

## 17.1 배경 제거

색상 키잉보다 매팅 기반 배경 제거를 사용한다.

이유:

- 회색조 그림자가 캐릭터 내부에 존재할 수 있음
- 흰자/밝은 의상 등이 배경으로 오인될 수 있음
- 단순 색상 제거는 내부 픽셀을 손상시킬 수 있음

### 반드시 사람 검수

특히 다음을 확인한다.

- [ ] 눈 흰자가 뚫리지 않음
- [ ] 밝은 피부가 뚫리지 않음
- [ ] 밝은 의상이 뚫리지 않음
- [ ] 머리카락 끝이 과도하게 잘리지 않음
- [ ] 반투명 외곽이 과도하게 남지 않음

## 17.2 Alpha 정리

- 외부의 불필요한 낮은 alpha 제거
- 내부의 정상적인 불투명 영역은 255로 정규화
- alpha가 0인 픽셀의 RGB도 정리
- 캐릭터 외곽의 halo 제거

# 18. 최종 출하 규격

4방향 기본 시트:

```text
1088 × 608
```

최종 출하 캔버스:

```text
246 × 493
```

게임 표시 높이:

```text
96 units
```

정렬 규칙:

- 크기 변경 금지
- 평행 이동만 허용
- 발 밑선 기준
- 발 중심 기준
- 캐릭터 세로 크기 기준 통일
- 12장의 상대 크기 유지

목표 허용차:

- 캐릭터 세로 크기: 서로 4% 이내
- 좌/우 측면 캐릭터 가로 크기: 서로 5% 이내
- 발 밑선: 동일 기준선
- 관절 기준점: 동일 좌표 체계

---

# 19. Spine 리깅 기준

Spine Essential을 사용한다.

기본 전제:

- 강체 파츠 중심
- 메시 변형에 의존하지 않음
- 개별 손가락 애니메이션 없음
- 파츠 회전 중심의 애니메이션
- 스킨 교체 지원

따라서 생성 단계에서 다음이 중요하다.

> **손 모양, 파츠 경계, 관절 위치는 생성 시점에 확정한다.**

리깅에서 해결할 수 없는 것을 생성 단계에서 넘기지 않는다.

---

# 20. 무기 교체 구조

기본 방식:

```text
손 = 고정 베이스
무기 = 독립 스킨
```

무기가 손 위를 지나가는 구조를 사용한다.

장점:

- 무기 추가 시 손을 다시 만들 필요가 없음
- 장갑 스킨과 무기를 독립적으로 교체 가능
- 스킨 × 무기 조합 폭발을 줄임

주의:

- 무기 손잡이는 손의 grip opening보다 충분히 가늘어야 한다.
- 지나치게 굵은 손잡이는 별도 손 베이스가 필요할 수 있다.

---

# 21. 작업 순서

최종 작업 순서는 다음으로 고정한다.

```text
[1]
Base Character Master 확정
        ↓
[2]
4방향 기본 캐릭터 생성
        ↓
[3]
4방향 동일성/크기/발밑선 검수
        ↓
[4]
Base Body / Hair / Clothing / Gloves / Boots / Staff
각 파츠를 4방향으로 생성
        ↓
[5]
각 파츠의 정렬/가림/동일성 검수
        ↓
[6]
필요한 Hair-Off / Clothing-Off 변형 생성
        ↓
[7]
배경 제거
        ↓
[8]
Alpha 검수 및 정리
        ↓
[9]
출하 규격 정렬
        ↓
[10]
Spine Essential 리깅
        ↓
[11]
스킨 / 장비 교체 구현
```

# 22. 가장 중요한 운영 규칙

## Rule 1 — Base Master는 정본이다

Base Master가 확정되면 이후 작업에서 체형을 개선하지 않는다.

## Rule 2 — 후속 생성은 "새 캐릭터 생성"이 아니다

항상 Base Master를 기준으로 **보존 + 파츠 추가/제거**를 수행한다.

## Rule 3 — 크기와 각도를 절대 독립적으로 판단하지 않는다

모든 파츠는 동일한 캐릭터 좌표계에 존재해야 한다.

## Rule 4 — 예쁜 결과보다 파츠 분리가 우선이다

게임 화면에서 예쁜지보다 다음 질문을 먼저 한다.

> "이 파츠를 떼어냈을 때 아래 파츠가 온전히 존재하는가?"

## Rule 5 — 생성 모델이 수정하면 안 되는 부분을 명시적으로 잠근다

특히:

- 머리 크기
- 얼굴
- 체형
- 다리 길이
- 다리 굵기
- 골반
- 팔/손
- 포즈
- 캐릭터 위치

는 후속 Edit에서 변경하지 않는다.

## Rule 6 — 결함을 다음 단계에서 보정하지 않는다

앞 단계에서 기준이 깨졌으면 뒤 단계에서 억지로 맞추지 않는다.

**앞 단계의 정본을 다시 생성하거나 해당 단계의 결과를 폐기한다.**

---

# 23. 현재 상태

현재 단계:

**Base Character Master 확정 단계**

현재 전제:

> **현재 정면 초안은 완벽한 정본이라고 가정한다.**

따라서 더 이상 초안의 디자인을 재검토하지 않는다.

다음 작업은:

```text
Base Character Master
        ↓
4방향 기본 캐릭터
```

이다.

이때부터 가장 중요한 검증 대상은 **캐릭터 동일성 + 비율 + 크기 + 각도 + 발 밑선 + 파츠 분리 가능성**이다.

---

# 24. 이후 프롬프트 작성 원칙

각 후속 프롬프트는 다음 순서를 따른다.

```text
1. Reference preservation
2. Exact character identity
3. Exact proportions
4. Exact scale / position
5. Required view or part
6. Occlusion constraints
7. Layer / separation constraints
8. Background constraints
9. Explicit forbidden changes
```

프롬프트가 길더라도 핵심 조건이 충돌하지 않는다면 상세하게 작성한다.

단, **한 프롬프트 안에서 여러 디자인 결정을 동시에 새로 만들지 않는다.**

---

# 25. 최종 성공 기준

이 프로젝트에서 아트 파이프라인의 성공은 다음과 같다.

> **하나의 확정된 캐릭터가 4방향에서 동일한 체형과 크기를 유지하고, 각 신체/의상/무기 파츠를 독립적으로 교체할 수 있으며, Spine에서 강체 파츠로 리깅되어도 파츠가 서로 관통하거나 빈 공간이 생기지 않는 것.**

즉,

```text
캐릭터 동일성
    +
4방향 일관성
    +
파츠 독립성
    +
가림 최소화
    +
정렬 가능성
    +
스킨 교체 가능성
```

을 동시에 만족해야 최종 아트 기준을 통과한다.
