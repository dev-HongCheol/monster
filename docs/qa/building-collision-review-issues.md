### 리뷰어 확인 강점 (요약)

- 근본 원인 분석(`speed·sin(θ)` 유도, 정지점이 끌개) 독립 재계산 일치. 개정 이력이 원 전제가 틀렸음을 덮지 않고 남긴 점.

- `STEER_EPS`를 서로 반대 방향으로 쓰는 것(막힘엔 축소, 가시성엔 확대)은 옳고 보수적인 방향이다.
- `MovementLogic` 무변경 diff 확인. 돌진 예외 배치·유격 후퇴를 호출부 특례 대신 함수 내부 `dot ≤ 0` 게이트로 처리한 것이 옳은 분리.
- 코어 수정은 실제로 동작한다 — 단일 박스 2,200여 위치 + 링 조합 + 200px 간격 2박스 전수에서 실패 0.
