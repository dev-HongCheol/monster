## 3. 씬/프리팹 변경 사항

**없음.** 새 노드·프리팹 추가 없음. 기존 적 프리팹 1종을 그대로 재사용하고, 스폰 시 `enemyId`만 코드로 주입한다.

> 적 3종이 **같은 스프라이트로** 스폰된다(시각 구분은 S2). 차이는 이동 속도·맷집·접촉 대미지로만 드러난다.

## 4. 에디터 연결 체크리스트

| 노드 / 컴포넌트 | 프로퍼티 | 설정값 | 상태 |
|----------------|----------|--------|------|
| WaveManager (main.scene) | `waveDuration` | **60** (기존 180에서 변경) | ⬜ |

> **중요(Cocos 직렬화):** `@property` 기본값을 코드에서 180→60으로 바꿔도, **씬에 이미 배치된 WaveManager 인스턴스는 직렬화된 값(180)을 유지**한다. 반드시 에디터에서 WaveManager 노드의 `waveDuration`을 직접 **60**으로 바꿔야 1분 웨이브가 적용된다. (안 바꾸면 코드 기본값은 60이지만 씬값 180이 우선.)
>
> EnemySpawner는 별도 에디터 변경 없음 — 스폰 테이블은 `DataManager`가 자동 로드, 디렉터는 `EnemySpawner`가 코드에서 생성.

## 5. 수동 테스트 체크리스트 (인게임)

> 1분 웨이브 + xp +10이라 빠르게 진행하며 확인.

- [ ] **웨이브 1 (0~1분):** 대부분 표준 적, 가끔 **눈에 띄게 빠른** 적(스워머). 탱크(아주 느리고 잘 안 죽는 적) **안 보임**.
- [ ] **웨이브 3 (2~3분):** 빠른 적 비중이 확 늘어남(스위프트 50). 느리고 단단한 탱크도 가끔 섞임.
- [ ] **웨이브 6 (5~6분):** **표준 적이 사라짐.** 빠른 적 + 느리고 단단한 적만. 표준 속도(150)의 적이 안 보이면 OK.
- [ ] **탱크 체감:** 어떤 적은 평소보다 훨씬 많은 타격을 버티고(320HP) 느리게(80) 다가옴.
- [ ] **스워머 체감:** 어떤 적은 빠르게(280) 달려들지만 한두 방에 죽음(50HP). 속도 차이가 한눈에 보임.
- [ ] **웨이브 진행(★ 리워크 수정):** 레벨업/카드 선택을 여러 번 해도 약 60초마다 웨이브 번호가 오른다. (수정 전: 레벨업마다 타이머가 60초로 리셋돼 웨이브가 1에 멈췄음.)
- [ ] **웨이브 길이:** 각 웨이브가 약 1분.
- [ ] **회귀:** 적 스폰·플레이어 추적·접촉 대미지·사망 시 XP 드롭 정상.
- [ ] **회귀:** 적이 스폰될 때 항상 올바른 스탯으로 나옴('skeleton'으로 잘못 로드되는 일 없음 — enemyId 주입 타이밍).

## 6. 알려진 한계 (이번 슬라이스)

- 세 적이 **시각적으로 동일**하다(같은 스프라이트). 종류 구분은 움직임·맷집으로만. → S2에서 색·크기로 해결.
- `waveDuration=60`, `xpDrop +10`, `swift speed 280`은 **테스트 편의값** — 출시 전 밸런싱에서 재검토.

## 7. 리워크 수정 (user-verification 발견)

수동 검증 중 발견·처리한 항목.

| # | 증상 | 원인 / 처리 | 상태 |
|---|------|------------|------|
| 1 | 3분이 지나도 웨이브가 1에 멈춤 | **버그.** `GameManager.resumeFromLevelUp` → `WaveManager.resumeWave()`가 레벨업마다 웨이브 타이머를 60초로 리셋. xp +10으로 레벨업이 잦아 타이머가 0에 도달하지 못함. 타이머는 LevelUp 동안 state 가드로 이미 멈춰 있으므로 **`resumeWave()` 리셋을 제거**(재개 시 이어서 흐름). | 수정됨 |
| 2 | 웨이브 1에서 swift가 안 보임 | **버그 아님.** 코드·데이터 경로 정상(wave 1 = swift 20%). S1은 셋이 같은 스프라이트라 유일한 단서가 속도인데 230(skeleton 150의 1.53배)이 난전에서 구분이 약했음 + #1로 웨이브가 안 올라 분포가 wave-1에 고정. **swift speed 230→280**(1.87배)으로 육안 구분 강화. 시각 구분 자체는 S2 영역. | 처리됨(속도 재조정) |
