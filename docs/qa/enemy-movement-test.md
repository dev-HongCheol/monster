## 씬/프리팹 변경 사항 — 사용자가 만들 에셋 (7단계)

### `Enemy.prefab` — 돌진 바닥 마커 자식 노드 추가

불가사리 돌진 텔레그래프(돌진 방향·도달 거리 표시)용 placeholder 막대다. 모든 적이 `Enemy.prefab` 하나를 공유하므로 이 노드도 모든 적에 존재하지만, **돌진 적의 윈드업에서만 활성화**되고 그 외에는 컨트롤러가 비활성으로 둔다.

| 항목 | 값 |
|---|---|
| 노드 이름 | `LungeMarker` |
| 부모 | `Enemy` 루트 노드(적 본체 Sprite와 형제, 본체 **아래** 레이어 — 바닥 마커이므로 형제 순서상 본체보다 먼저) |
| 컴포넌트 | `cc.Sprite` 1개 |
| SpriteFrame | Cocos 기본 단색(예: `default_sprite_splash` 또는 내장 흰 사각형). placeholder라 어떤 단색 사각 스프라이트든 가능 |
| Sprite Type | `SLICED` 또는 `SIMPLE` (단색 막대라 무방) |
| 색(Color) | placeholder 빨강 계열(예: `#FF4040`, 알파 ~160). 컨트롤러가 색을 따로 건드리지 않으므로 에디터 값이 그대로 보인다 |
| Anchor | **X=0, Y=0.5** (왼쪽 끝 기준 — 적 중심에서 돌진 방향으로 뻗어나가도록) |
| Content Size | 폭 100 × 높이 8 (기준 크기. 런타임에 길이는 스케일로, 회전은 angle로 컨트롤러가 조절) |
| Position | (0, 0) — 적 중심 |
| 초기 Active | **꺼짐(비활성)** — 컨트롤러가 윈드업에만 켠다 |

> 컨트롤러가 윈드업 동안 `LungeMarker.active=true`로 켜고, 각도 = 돌진 방향(`vectorToAngle`), X 스케일 = `lungeReach / 100 / 부모 threatScale`(기준 폭 100·부모 스케일 상쇄)로 길이를 맞춘다. 그 외 상태·다른 적에서는 항상 비활성이다. **마커를 안 만들어도(@property 미연결) 게임은 동작한다** — 컨트롤러가 null 가드로 마커 없이 돌진·점멸만 수행한다(점멸 텔레그래프는 본체 색이라 마커와 무관).

`EnemyController`(`Enemy.prefab` 루트에 부착됨)에 프로퍼티가 1개 추가된다.

| @property | 연결 대상 | 상태 |
|---|---|---|
| `lungeMarker` (Node) | `Enemy/LungeMarker` 자식 노드 | ❌ 미연결 (7단계에서 연결) |

> 윈드업 점멸 색은 코드 상수라 에디터 연결이 없다. 기존 프로퍼티(`playerNode`·`xpItemPrefab`·`flashDuration` 등)는 변경 없음.

## 수동 테스트 체크리스트 (인게임 — 코드로 검증 불가)

> **사전 안내(중요):** 이 슬라이스에서 **불가사리 돌진은 "텔레그래프 + 이동" 수직 슬라이스**다. office-hours D1 결정으로 돌진 데미지는 기존 접촉 경로를 쓰는데, 돌진이 워낙 빨라 플레이어를 관통하며 입히는 접촉 피해가 미미하다. 즉 **"돌진이 데미지를 거의 안 준다"는 정상이며 버그가 아니다** — 실질 돌진 데미지는 S2의 능동 공격 버스트에서 들어온다. 이 단계에서 봐야 할 것은 *이동·텔레그래프*가 또렷한지다.

### 어둑시니 (지그재그)
- [x] 어둑시니가 플레이어로 다가오되 **좌우로 흔들며(사인파)** 온다 — 직선이 아니다.
- [x] 흔들림이 한쪽으로만 쏠리지 않고 좌우 대칭으로 진동한다.
- [x] 플레이어가 가만히 있을 때 발사체(직선 조준)가 어둑시니를 더 자주 빗나간다(지그재그의 회피 압박 체감).
- [x] 접촉 피해·피격 플래시·사망 연출은 기존 적과 동일하게 작동한다.

### 불가사리 (돌진 + 텔레그래프)
- [x] 평소에는 다른 적보다 **느릿하게** 추격한다.
- [x] 플레이어가 일정 거리(`lungeRange`) 안에 들면 **잠깐 멈칫(윈드업)** 하며 본체 색이 빨갛게 점멸(램프)한다.
- [x] 윈드업 동안 **바닥에 돌진 방향·도달 거리를 가리키는 막대 마커**가 적에서 플레이어 쪽으로 뻗어 보인다.
- [x] 윈드업이 끝나면 마커 방향으로 **빠르게 미끄러지듯 돌진**하고, 돌진 끝에서 잠시 멈춘다(쿨다운).
- [x] 돌진은 윈드업 때 가리킨 방향으로만 간다 — 윈드업 중 플레이어가 옆으로 피하면 돌진은 빗나간다(방향 잠금).
- [x] 돌진 직후 곧바로 다시 돌진하지 않는다(쿨다운 동안 추격만).
- [x] 큰 적(threatScale)이라 마커 길이가 **부풀지 않고** 실제 돌진 도달 거리와 일치한다(부모 스케일 상쇄 확인).

### 텔레그래프 × CC 상호작용
- [x] 윈드업/돌진 중 정지(라이트닝 볼트 등)에 맞으면 **그 자리에 얼어붙고**, 정지가 풀리면 **남은 돌진을 마저** 한다(돌진이 정지 시간만큼 헛돌지 않음).
- [x] 윈드업 중 불가사리를 처치하면 바닥 마커가 **즉시 사라지고** 사망 연출(팝·페이드)만 남는다(마커가 시체에 남지 않음).
- [x] CC 틴트(정지=노랑 등)와 텔레그래프 빨강·피격 플래시 흰색이 겹칠 때 색이 깨지거나 한 색에 박히지 않는다(우선순위: 사망>플래시>텔레그래프>CC>기본).

### 회귀 (기존 적)
- [x] 처녀귀신·도깨비·달걀귀신·장산범이 **여전히 직선 추격**하고 접촉·피격·사망·CC가 그대로다(movement 분기가 chase 경로를 안 건드림).
- [x] 풀 재사용 후(웨이브 진행) 불가사리가 **돌진 중간 상태나 멈춘 마커를 달고 스폰되지 않는다**(reset 초기화 확인).
