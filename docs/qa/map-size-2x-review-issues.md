## 요약

데이터(size + 한강 14정점 ×2)·경계 불변식·서브스텝 재검증 산수·"맵 크기 하드코딩 없음" 주장이 전부 코드와 정합하고, 로직은 한 줄도 바뀌지 않았으며 전체 스위트 550/550 GREEN을 리뷰어가 직접 확인했다. 강점으로 든 것:

- 14정점 전부 정확히 ×2(개별 검산), `size` 정확히 `[4800,4800]`, 배율 불변.
- `MapManager._hasVertexOutside`(엄격 부등호 `> halfW`)와 정합 — 스케일 후 최대 |x| = 2400 = 새 halfW라 벽에 앉고 경고 미발화, 최대 |y| = 1200 < 2400.
- `2400/1200/4800` 전역 grep으로 "하드코딩 없음" 실증 — 카메라 클램프·`ArenaLogic`·`PlayerController`·발사체 컬링·스포너·`SpawnGeometry`가 전부 `MapManager.arena`(=`map.size`)에서 유도.
- `ObstacleLogic` 주석 재검증 산수 정확(6788/64≈106 < 120+2×18=156) + 상수·코드 불변.

## Minor 이슈 (2건 — 둘 다 이 슬라이스 스코프 밖, 백로그로 집약)

### M-1 — "표준 서울 아레나 2400" 테스트 픽스처 라벨이 실제 맵(4800)과 어긋남
- **위치:** `tests/logic/MapArena.test.ts:20-21`, `tests/logic/SpawnGeometry.test.ts:36-37`
- **내용:** 두 테스트가 `ARENA = { width: 2400, height: 2400 }`를 "표준 서울 아레나(placeholder 크기)"로 라벨링한다. 이번 슬라이스로 실제 서울은 4800이 됐으므로 이 고유명 라벨은 사실과 어긋난다. **테스트 로직은 크기 불가지라 통과 무영향 — 순수 가독성 문제.**
- **처리:** **이 슬라이스에서 수정 안 함.** 무관 파일 수정 규칙(현재 작업과 무관한 파일 수정 금지) + 리뷰어도 "강제 아님"이라 판단. → 백로그 **F54**로 집약(`backlog-implement.md` § 정리·리팩터).

### M-2 — 서브스텝 관통 마진이 절반으로 줄었고 "최소 변 120px" 전제가 코드로 미강제
- **위치:** `game/assets/scripts/logic/ObstacleLogic.ts:31-32`(주석), `systems/MapManager.ts` 색인 검증
- **내용:** 서브스텝 길이 상한이 2400 시절 ~53px에서 4800에서 106px로 약 2배가 되어, 하한 156px 대비 여유가 ~103px→~50px로 줄었다. **여전히 106 < 156이라 결론(관통 없음)은 유지**되지만, 이 마진은 "장애물 최소 변 120px" 전제에 기대고 MapManager는 최소 변 하한을 강제하지 않는다(크기 0·300px 초과만 경고). 한 변 ~70px 미만 박스를 극단 dt에서 놓으면 이론상 관통 가능. **회귀 아님**(실사용 박스 최소 120px, 극단 dt≈17.8초급에서만 발현). "120px" 전제는 이 슬라이스가 아니라 building-collision 때부터 있던 것.
- **처리:** **이 슬라이스에서 코드 수정 안 함**(리뷰어 "필수 아님", 머지 무방). → 백로그 **F55**로 집약(`backlog-implement.md` § 데이터 불변식, F50·D2 인접).
