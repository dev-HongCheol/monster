### 2. F160 행이 `wf` 경로에는 머지를 막는 장치가 있는 것처럼 읽혔다
- 위치: `docs/development/backlog-implement.md` F160 행, 계획 §3 「F160 행 전문」
- 행은 문서 작업 경로에 「`gh pr merge`를 막는 장치도 없다」고 적고 괄호에서 `pass review`만 바로잡았다. 그래서 `wf` 경로에는 그런 장치가 있다고 읽힌다. 실제로는 `gate-scripts.mjs` 훅이 Write · Edit만 보고 `gh pr *`는 허용 목록에 있어서, 머지를 늦추는 것은 Draft 상태뿐이고 그것도 AI가 `gh pr ready`로 풀 수 있다. F160을 맡는 사람이 「`wf`에 있는 장치를 문서 경로로 넓히면 된다」고 출발하면 없는 장치를 찾게 된다.
- 수정: 「`gh pr merge`를 막는 장치는 두 경로 모두 없다」는 문장을 따로 두고, `pass review`가 리뷰를 실제로 했는지 확인하지 않고 상태 파일에 적기만 한다는 것과 Draft 상태를 AI가 풀 수 있다는 것을 적었다. 계획의 전문도 같은 문구로 고쳤다.
- **수정됨** ✅
