# 발사체 일시정지 가드 (I1) — QA / 테스트

- **브랜치:** feat/projectile-pause-guard
- **계획:** [2026-07-01-projectile-pause-guard-plan.md](../development/sessions/2026-07-01-projectile-pause-guard-plan.md)
- **요지:** 레벨업 카드 선택으로 게임이 멈춘 동안, 이미 날아가던 발사체 두 종류(`Projectile`·`EnemyProjectile`)도 함께 멈춰야 한다. 두 `update()` 맨 앞에 `state !== Playing` 가드를 추가해 다른 시스템(`SpellCaster`·`EnemyController` 등)과 정합을 맞춘다.

---

## 자동 테스트 — 스킵(skip-test)

추가하는 가드는 Cocos 라이프사이클 메서드(`update()`) 맨 앞에서 싱글톤 상태(`GameManager.instance.state`)를 읽는 프레임워크 배선이라, 분리해 단위 테스트할 순수 로직 모듈이 없다. 코드베이스의 동일한 가드(`SpellCaster:154`·`EnemyController:218`)도 같은 이유로 단위 테스트가 없다. → `pnpm wf skip-test`로 처리.

검증은 **전체 vitest 스위트 GREEN 유지(회귀 없음)** + 아래 **인게임 수동 체크리스트**로 한다.

> **GREEN 통과(회귀 없음):** 전체 스위트 **344/344**(27개 파일). 발사체·폭발·상태이상 기존 테스트 전부 통과 — 가드 추가가 정상 플레이 경로(`state === Playing`)에 회귀를 일으키지 않음을 확인.

---

## Impact Map (회귀 기준)

| 변경 파일 | 확인 범위 |
|---|---|
| `components/Projectile.ts` | `update()` 맨 앞 가드 추가. 정상 플레이(`state === Playing`) 중 이동·명중·폭발·화면 밖 반환은 그대로. 레벨업 중에만 정지 |
| `components/EnemyProjectile.ts` | `update()` 맨 앞 가드 추가. 정상 플레이 중 이동·플레이어 명중·화면 밖 반환은 그대로. 레벨업 중에만 정지 |

**회귀 확인 포인트:** 두 발사체의 기존 동작(이동·충돌 판정·폭발·풀 반환)은 `state === Playing`일 때 무변경이어야 한다. 가드는 일시정지 분기에만 작용한다. 기존 발사체·폭발·상태이상 단위 테스트가 전부 GREEN을 유지하는지로 회귀 없음을 확인한다.

## 씬/프리팹 변경 사항

**없음.** 가드는 기존 두 컴포넌트(`Projectile`·`EnemyProjectile`) 내부 `update()`에만 들어간다. 새 노드·프리팹·아트 에셋·`@property`를 추가하지 않는다.

## 에디터 연결 체크리스트

**없음.** 신규 `@property`가 없어 에디터에서 새로 연결할 항목이 없다. (씬·프리팹 설정 변경 없이 코드만 갱신.)

## 수동 테스트 체크리스트 (인게임)

> 코드로 검증 불가한 인게임 동작만. 에디터 세팅은 필요 없다(노드/프로퍼티 변경 없음). 레벨업이 자주 뜨도록 경험치를 빠르게 모으거나, 발사체가 화면에 떠 있는 순간 레벨업이 걸리도록 유도한다.

> **7단계 통과(2026-07-01, 사용자 인게임 테스트):** 발사체 정지·무피해·재개가 모두 정상 확인됨 → `PR 승인`. wave 1에 `imugi`/`mulgwisin`을 끌어와(spawn-table 임시 튜닝, 비커밋) 발사체를 조밀하게 띄워 검증.

- [x] **적 발사체 정지:** 적 발사체(물귀신 확산 8발처럼 느리고 다수면 관찰 쉬움)가 날아오는 중 레벨업 → 카드 선택 패널이 떠 있는 동안 적 발사체가 **제자리에 멈춘다**.
- [x] **메뉴 중 무피해:** 위 상황에서 패널이 떠 있는 동안 플레이어 HP가 **줄지 않는다**(멈춘 발사체가 닿아도 `damagePlayer`가 호출되지 않음).
- [x] **플레이어 발사체 정지:** 플레이어 발사체(느린 다발·폭발형이면 관찰 쉬움)가 날아가는 중 레벨업 → 발사체가 **멈추고**, 멈춰 있는 동안 적에게 명중·폭발 데미지가 들어가지 않는다.
- [x] **재개 정상 동작:** 카드를 고르고 게임이 재개되면 멈췄던 발사체들이 **다시 정상적으로 이동**하고, 이후 명중·폭발 판정이 정상 동작한다(가드가 재개를 막지 않는다).

> **7단계에서 발견한 별개 이슈(이 슬라이스 범위 밖 → 백로그 I3):** 정지한 발사체가 카드 선택 패널 **위로** 렌더돼 카드 이름/설명 글씨를 가린다. 가드는 정상 동작(발사체가 멈춤)이고, 이는 멈춤으로 가시화된 **렌더 레이어** 문제다 — 발사체를 덱 UI 뒤로 렌더하는 후속(백로그 I3)으로 분리. 사용자 판단으로 이 PR은 그대로 승인.
