# magic-slow QA 테스트 — 슬로우(아이스 미사일) + CC 다중 타이머 모델(F14)

> **브랜치:** feat/magic-slow
> **슬라이스:** 마법 효과 레이어 magic-S3 (슬로우 + CC 다중 타이머)
> **계획 문서:** `../development/sessions/2026-06-21-magic-slow-plan.md`

아이스 미사일이 명중 시 적을 감속(슬로우)시키고, CC 모델을 단일 슬롯에서 강도별 다중 타이머로 바꾸는 슬라이스다. 슬로우가 두 번째 강도라 정지·슬로우가 한 적에 겹칠 때 "강한 게 먼저 만료되며 색·동작이 전환"되는 게 본체다.

## 씬/프리팹 변경 사항

이 슬라이스는 **새 노드·프리팹이 필요 없다.** 슬로우 틴트(하늘색)는 기존 적 스프라이트 색에 적용하고, 슬로우 동작은 데이터(`spells.json`) + 순수 로직 + 기존 컴포넌트로 처리한다.

---

## 에디터 연결 체크리스트

`@property` 신규 연결은 없다. 다만 인게임 검증을 위해 **시작 마법을 임시로 바꾼다**(계획 §7).

- [ ] **(테스트 전용)** `Player` 노드의 `SpellCaster` → `startingSpellIds`를 `['ice_missile', 'lightning_bolt']`로 설정 (슬로우 단독 확인 + 정지와 겹치는 다중 타이머 확인을 위해 둘 다). 코드 기본값을 임시 변경했다면 인스펙터를 비워 코드값이 먹게 하고, 인스펙터에 값이 있으면 인스펙터에서 바꾼다 — 한 곳으로 통일.
- [ ] (선택) 적을 1~2마리로 줄이거나 HP를 올려, 슬로우/정지가 풀리기 전에 적이 죽지 않게 해 관찰을 쉽게 한다 (비커밋)

## 수동 테스트 체크리스트

코드로 검증 불가한 인게임 동작만:

- [ ] 게임 시작 시 아이스 미사일이 자동 발사된다(임시 시작 마법 적용 확인)
- [ ] 아이스 미사일 명중 시 적이 **느려진다**(멈추지 않고 감속 — 정지와 구분)
- [ ] 슬로우된 적에 **하늘색 틴트**가 보인다(`Color(130,200,255)` placeholder)
- [ ] 슬로우된 적이 플레이어에 닿아 있으면 **접촉 피해가 계속 들어온다**(슬로우는 감속만 — §9.4)
- [ ] 슬로우 지속이 끝나면 적이 **원래 속도로** 추격한다
- [ ] **다중 타이머 겹침:** 한 적에 정지(라이트닝 볼트) + 슬로우(아이스 미사일)가 겹치면 → **정지색(노란)으로 멈췄다가 정지가 풀리면 슬로우색(하늘)으로 감속 전환**된다(약한 슬로우가 정지를 5초로 늘리지 않음 — 정지는 제 지속만)
- [ ] **정지 틴트가 magic-S2와 시각적으로 동일**하다(번개 노란색 불변 — 모델 재작성이 정지 룩을 안 바꿈)
- [ ] 슬로우/정지 틴트가 **피격 플래시·사망 페이드 연출을 깨지 않는다**(우선순위 사망>플래시>CC>기본)
- [ ] 레벨업 카드에 아이스 미사일 **지속시간 강화 카드**가 등장한다(개별/분류)
- [ ] 지속시간 강화를 픽하면 이후 슬로우가 **더 길게** 유지된다
- [ ] 다른 시작 마법(파이어볼)으로 바꿔도 슬로우 미발동·기존 동작 정상(회귀)
- [ ] **머지 전 복원:** `startingSpellIds`를 `['fireball']`로 되돌렸다(테스트 전용 변경 — 계획 §7)
