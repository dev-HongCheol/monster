## 수동 테스트 체크리스트 (7단계 인게임)

> 핵심: **그리드로 바꾼 뒤에도 명중 판정이 종전과 똑같아야 한다.** 누락된 명중이 생기면 그리드 질의가 후보를 빠뜨린 것이다.

- [ ] **대량 적 스트레스:** 인스펙터에서 `EnemySpawner.maxEnemies`를 크게(예: 300~500) 임시로 올린다(**비커밋**). 수백 마리가 화면에 깔린 상태에서 발사체가 적을 정상적으로 맞히는지, 통과해 버리는(명중 누락) 적이 없는지 확인한다.
- [ ] **빠른 적 / 화면 가장자리:** 빠르게 움직이는 적이나 화면 가장자리에서 들어오는 적도 정상 명중하는지(셀 경계·프레임 낡음으로 인한 누락이 없는지).
- [ ] **폭발 마법(파이어볼):** 군집에 폭발이 터질 때 범위 안 적이 모두 피해를 받고, 같은 시전이 한 적을 1회만 때리는(중복 제거) 동작이 종전과 같은지.
- [ ] **체감 프레임:** `maxEnemies`를 올린 상태에서 프레임이 종전 대비 유지·개선되는지(전수 비교 때 끊기던 구간이 매끄러워지는지). 정밀 측정은 후속(S2·S3 이후) 과제.
- [ ] **원래 값 복원:** 테스트 후 `maxEnemies` 임시 상향을 **되돌렸는지**(커밋에 섞이지 않도록).

## 메모

- `maxEnemies` 상한 자체를 제거하는 것은 S3(스폰·난이도) 슬라이스다. S1에서는 상한을 유지하고 스트레스 테스트용으로만 임시 상향한다.
- 정량 프레임 측정(드로우콜·GC 프로파일)은 할당 위생(S2)·캡 제거(S3)까지 끝난 뒤 대량 적 상태에서 종합한다.
