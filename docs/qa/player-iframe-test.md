# 플레이어 피격 무적(i-frame) + 틱당 max 피해 게이트 — QA / 테스트

- **브랜치:** feat/player-iframe
- **계획:** [2026-06-27-player-iframe-plan.md](../development/sessions/2026-06-27-player-iframe-plan.md)
- **요지:** 플레이어는 고정 주기 `T`(피격 틱 = 무적 구간)마다 피해를 1회만 받고, 그 값은 그 틱에 들어온 피해원 중 가장 센 것이다. 접촉 피해도 이 게이트를 지나므로 "초당 DoT(닿은 적 합산)"에서 "틱당 max"로 바뀐다.

## Impact Map (회귀 기준)

| 변경 파일 | 확인 범위 |
|---|---|
| `logic/PlayerDamageLogic.ts`(신규) | 순수 테스트 전수(위 자동 테스트) |
| `systems/GameManager.ts` | `damagePlayer`가 즉시 차감 → 틱 제출로 전환. `update`가 틱마다 누적 max를 HP에서 차감. HP ≤ 0이면 기존대로 GameOver 전이·result 씬 이동이 **틱 경로에서** 정상 동작 |
| `components/EnemyController.ts` | `_checkContactDamage`가 `× dt` 즉시 차감 → `× T` 틱 제출로 전환. 접촉 피해가 의도대로(틱당 max, 떼 둘러싸도 합산 없음) |

**의도된 동작 변경(회귀 아님):** 접촉 떼 합산 폐기. 이미 머지된 적(S0~S1)의 접촉 체감이 바뀐다 — 아래 수동 체크리스트에서 의도된 변경임을 확인한다.

## 씬/프리팹 변경 사항

**없음.** 게이트는 기존 `GameManager`(이미 `_playerHp`·`update`·`damagePlayer` 소유) 내부에 들어가고, 순수 로직과 `EnemyController` 접촉 경로 리팩터뿐이다. 새 노드·프리팹·아트 에셋을 추가하지 않는다.

## 에디터 연결 체크리스트

**없음.** 신규 `@property`가 없다. 피격 틱 시간 `T`는 코드 상수(placeholder)로 두며 인스펙터 노출은 밸런싱 단계 Open Item이다.

## 수동 테스트 체크리스트 (인게임)

> 코드로 검증 불가한 인게임 동작만. 에디터 세팅은 필요 없다(노드/프로퍼티 변경 없음).

- [x] **단일 근접 적 접촉:** 적 한 마리에 닿아 있을 때 HP가 기존과 비슷한 속도로 깎인다(평균 피해율 보존).
- [x] **떼 둘러싸임(핵심 변경):** 근접 적 여러 마리에 동시에 둘러싸여도 HP가 **가장 센 한 마리만큼만** 깎인다(예전처럼 마릿수에 비례해 합산되지 않는다). — 의도된 변경.
- [x] **무적 구간:** 한 번 피해를 받은 직후 짧은 시간(`T`) 동안은 추가 피해가 들어오지 않는다.
- [x] **틱당 max:** 강한 적과 약한 적이 동시에 닿으면 그 틱엔 강한 적의 피해가 들어온다(약한 쪽만 맞는 일이 없다).
- [x] **사망 전이:** 누적 피해로 HP가 0이 되면 정상적으로 GameOver → result 씬으로 이동한다(틱 경로로 옮긴 뒤에도 동작).
- [x] **돌진 적(불가사리) 회귀:** 돌진/접촉 피해가 이 게이트를 지나도 기존처럼 정상 동작한다.

> 후속 슬라이스(적 발사체 S2a)에서 발사체 명중 피해가 이 게이트를 지나는지는 그 슬라이스 QA에서 확인한다.
