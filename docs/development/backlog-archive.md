# 완료 아카이브 — 게임

> **무엇인가.** [`backlog.md`](backlog.md)에서 완료된 항목을 옮겨 둔 곳이다. 항목별 요약과 출처 링크만 있으며, **"그 결정이 어느 슬라이스에서 났나"를 찾을 때 세션 폴더를 뒤지기 전에 여기서 먼저 찾는다.**
>
> **왜 갈라 뒀나(2026-08-06).** 슬라이스를 시작할 때 읽어야 하는 것은 백로그의 **열린 항목**뿐인데, 아카이브가 같은 파일에 있으면 조회할 때마다 통째로 함께 읽힌다. 아카이브가 필요한 시점은 과거를 되짚을 때뿐이라 그때만 열도록 뺐다.
>
> **항목 ID는 영구하다** — 파일이 갈려도 `F38`·`B2`는 그대로다. 운영 규칙·상태 어휘의 정본은 [`backlog.md`](backlog.md) 머리말이다.
