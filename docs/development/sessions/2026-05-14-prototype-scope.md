# 프로토타입 스코프 결정 — 오피스 아워 세션

- **날짜:** 2026-05-14
- **담당자:** 개발자 (devHong)
- **단계:** 개발 / 학습
- **상태:** APPROVED

## 배경 및 목표

TS 프론트 개발자가 Cocos Creator를 처음 배우며 로그라이크 액션 게임을 만든다.
최종 목표는 실제 제품 출시. 현재는 기획 완성, 코드 없음.

## 확정된 전제

1. **전투 루프 먼저** — 비주얼/시너지는 전투가 작동한 이후에 얹는다
2. **Cocos Creator 유지** — TypeScript 친숙도 + 모바일 타겟에 적합
3. **한국 챕터 1개로 시작** — 3개국 동시 개발은 학습 중 완성 불가
4. **솔로 개발** — 아트는 AI 파이프라인, 코드는 본인

## 검토한 접근법

| 접근법 | 내용 | 규모 | 위험도 |
|--------|------|------|--------|
| **A (선택)** | 최소 전투 프로토타입 — 이동+공격+적+충돌+HP | S | 낮음 |
| B | 버티컬 슬라이스 — 방→보스→드랍→다음 스테이지 | M | 중간 |
| C | Phaser.js 전환 — 순수 TS+브라우저 | S | 중간 |

## 선택: A — 코코스 최소 전투 프로토타입

### 이유
엔진을 파악하는 속도가 전체 일정을 결정한다. 복잡한 시스템보다 Cocos의
노드/컴포넌트 구조를 먼저 손으로 이해해야 이후 시스템을 올바르게 얹을 수 있다.

### 완료 기준 (이 단계)

- [ ] 플레이어 이동 (키보드/터치)
- [ ] 공격 발사 (마법 프로젝타일)
- [ ] 적 1종 (플레이어 추적 AI)
- [ ] 충돌 감지 + HP 시스템
- [ ] 게임오버 / 재시작 플로우

아트 없이 색깔 사각형으로 시작한다.

## 이후 개발 순서

```
[현재] 최소 전투 루프
  ↓
한국 챕터 룸 구조 (다수 방, 이동)
  ↓
보스 + 아이템 드랍
  ↓
시너지 시스템 (국가 간 크로스 보너스)
  ↓
아트 에셋 교체 (Midjourney → Cocos)
  ↓
UI 다듬기
  ↓
일본/중국 챕터 추가
```

## 미결 사항

- Cocos Creator 3.x 최신 vs Cocos 4 (2026년 오픈소스화) — 버전 선택 필요
- 모바일 컨트롤 스킴 — 터치 vs 버추얼 조이스틱
- 아트 에셋 교체 시점 — 몇 단계까지 사각형으로 진행할지

## 이번 주 과제

Cocos Creator 프로젝트를 만들고, **색깔 사각형 하나가 움직이고 프로젝타일을 발사하게 만든다.**
아트는 넣지 않는다. 엔진이 오브젝트를 어떻게 관리하는지 이해하는 것이 목표.
