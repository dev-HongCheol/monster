## 핵심 결정 사항

### 게임 정체성
- **장르:** 정통 호드 서바이벌 로그라이크 + 덱 시스템
- **시점:** 탑다운 2D
- **그래픽:** 픽셀 아트 (AI 생성, 1주차 데모로 방식 확정)
- **IP:** 판타지 영웅(직업) vs 한국 귀신/요괴 — plan.md 시나리오 정렬

### 시스템
- **캐릭터:** 직업 3종 (마법사/성직자/드루이드), 시각·범위·패시브 차별화
- **마법 시스템:** 활성 슬롯 6개 동시 발사 (뱀서/Brotato 표준)
- **덱 시스템:** 카드 = 신규 마법 + 강화(어떤 마법에 적용할지 선택) + 패시브
- **마법 총 10종:** 시작 3 + 카드 풀 7
- **적:** 5종 (한국 요괴 모티프), v1은 단순 추격, 능동 공격 패턴은 v2

### 출시 패턴
- **2단계:** itch.io 무료 (17.5주) → Steam 유료 (+4.5개월)
- **모바일 비목표** (Steam 학습 가치 우선)

### 코드 원칙
- 데이터 주도 설계 (모든 콘텐츠 JSON)
- 객체 풀링 (6슬롯 동시 발사 + 적 다발)
- 단일 컨트롤러 + 데이터 분리

## 학습 (Learnings)

이번 세션에서 발견한 비자명한 통찰:

1. **인디 솔로 게임 + 스킨 판매 모델은 검증되지 않음** — 멀티/소셜 없으면 동기 부재. 트랜스모그는 좋지만 매출원으로는 약함.
2. **2단계 출시 (itch → Steam)가 솔로 인디 표준** — 첫 출시 경험을 빨리 얻고 데이터로 v2 방향 조정.
3. **뱀서/Brotato 같은 "단순한 호드"도 사실 정교한 덱 시스템** — 단순 픽업으로 보이지만 카드 슬롯 + 강화 선택 시스템이 있음. v1부터 본격 구현 필요.
4. **AI 그래픽 방식 결정은 실제 결과로** — 추측보다 1주 데모로 확정.
5. **Cocos 데이터 주도 설계는 v1부터** — 추후 v2 콘텐츠 추가 속도가 이 결정에 종속됨.
