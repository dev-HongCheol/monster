# 게임 개발 체크리스트 (Checklist)

## 1. 프로젝트 기초 설정 (Technical Foundation)
- [ ] Cocos Creator 3.x 프로젝트 초기화 및 세팅
- [ ] 다국어 지원(i18n) 시스템 구축 (한국어, 영어, 일본어, 중국어)
- [ ] 언어 선택에 따른 국가별 초기화 로직 구현

## 2. 핵심 시스템 구현 (Core Gameplay)
- [ ] **시나리오 및 연출:**
    - [ ] 오프닝 소환 컷씬/대화 시스템 (무당, 스님, 무녀 등 등장)
    - [ ] 퇴마사가 아닌 마법사 등장 시의 연출 및 대사 구현
- [ ] **플레이어 컨트롤러:** PC(키보드/마우스) 및 모바일(가상 조이스틱) 입력 대응
- [ ] **전투 시스템:** 공격 판정, 대미지 계산, 상태 이상 시스템
- [ ] **아이템 시스템:**
    - [ ] 옷, 음식, 악기, 유니크 아이템 랜덤 드랍 로직
    - [ ] 아이템 타입별 데이터 테이블 구축
- [ ] **챕터 관리:**
    - [ ] 4계절(봄, 여름, 가을, 겨울) 맵 로딩 및 전환 시스템
    - [ ] 보스 클리어 후 다음 계절 이동 로딩 화면 구현

## 3. 아트 및 최적화 (Art & Optimization)
- [ ] **2.5D 렌더링:** 3D 공간 내 2D 스프라이트 배치 및 뎁스(Depth) 설정
- [ ] **계절별 테마:** 
    - [ ] 국가별/계절별 배경 에셋 및 전용 요괴 스프라이트 제작
    - [ ] 계절별 사운드(BGM) 연동 시스템


## 4. 콘텐츠 및 기획 상세 (Content & World)
- [ ] **한국 챕터:** 12개월(절기)에 따른 배경 테마 및 요괴 리스트업
- [ ] **보스 기획:** 타락한 해태 등 각 국가별 최종 보스 패턴 설계
- [ ] **시나리오/텍스트:** 전 세계 신화 기반의 아이템 설명 및 도감 텍스트 작성
- [ ] **사운드:** 나라별 전통 악기(가야금, 샤미센, 징 등) 기반 BGM 및 효과음 확보

## 5. UI/UX 및 편의 기능 (UX & Settings)
- [ ] **메인 메뉴 시스템:**
    - [ ] 메인 히어로 이미지 및 타이틀 레이아웃 구성
    - [ ] 저장 데이터 유무에 따른 '이어하기' 메뉴 활성화 및 순서 변경 로직
    - [ ] '새 게임' 선택 시 기존 데이터 덮어쓰기 확인 팝업 구현
    - [ ] 환경설정 및 종료 버튼 기능 연결
- [ ] **설정 메뉴:** FPS 제한, 해상도 조절, 사운드 볼륨 제어 UI
- [ ] **반응형 레이아웃:** Widget 컴포넌트를 활용한 멀티 해상도 대응
- [ ] **도감/커스텀 창:** 획득한 유물 및 장착 중인 스킨 확인 화면
- [ ] **성장 체감 UI:** 마법 레벨업 및 시너지 획득 시 시각적 피드백 강화

## 6. 테스트 및 배포 (QA & Release)
- [ ] **성능 테스트:** 저사양 모바일 및 고사양 PC 144+ FPS 유지 확인
- [ ] **빌드 테스트:** Web, Android, iOS, Windows 빌드 안정성 검토
- [ ] **밸런스 조절:** 국가 간 시너지 및 아이템 위력 데이터 시뮬레이션
- [ ] **저작권 검토:** 사용된 모든 리소스의 저작권 및 라이선스 확인
