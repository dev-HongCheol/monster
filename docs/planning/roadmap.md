## 🔄 방향 전환 (v0.3, 2026-07-02) — 콘텐츠 동결, 완성도 우선

> **성격:** 사용자 방향 지시(2026-07-02)를 반영한 DRAFT. 완성도 영역의 우선순위와 슬라이스 분해는 후속 `/office-hours` 세션에서 확정한다.

**결정:** 마법과 적은 v1 콘텐츠를 **여기서 동결**한다. 앞으로 두 영역은 **버그 수정·밸런스 조정·현재 기준 마감**만 하고, 새 마법·새 적·새 효과·새 공격 패턴은 전부 **2차(v2)로 이월**한다. 대신 개발 축을 **게임 전체 완성도**로 옮긴다 — 맵 구성, 스토리 구성, 전체 게임 플로우, UI, 그리고 §7에 이미 잡혀 있던 메타 시스템(메인 메뉴·도감·세이브·20분 타이머와 클리어 조건·결과 화면·사운드).

**왜 지금인가 (초과 달성 정리):** 마법·적은 원래 v1 계획(§7)과 어긋난 방향으로 이미 깊게 만들어졌다.
- §7은 v1 적을 **5종·단순 추격 + 충돌**로 잡고 능동 공격 패턴을 명시적으로 v2에 위임했지만, 실제로는 **적 12종 + 능동 공격 전 종류**(발사체 단발·부채꼴·확산 / 근접 부채꼴 휘두르기 / 돌진 / 유격)까지 구현돼 §8의 v2 스코프를 이미 v1으로 당겼다.
- 마법은 반대로 **개수는 5종(파이어볼·아이스 미사일·라이트닝 볼트·프로스트 노바·인페르노)에서 멈춰 §7의 10종 목표에 미달**하지만, 효과 레이어(폭발·기절·둔화·노바·궤도)의 깊이는 §7이 상정한 "패턴 위주"보다 훨씬 깊다.

따라서 이 전환은 새 방향을 만드는 게 아니라, **이미 초과 달성한 두 영역을 잠그고 로드맵이 처음부터 v1에 넣기로 했던 미구현 '넓이'로 자원을 되돌리는 재조정**이다.

**받아들이는 트레이드오프:** 마법을 5종에서 동결하면 6슬롯 액티브 + 덱/카드 시스템이 상정한 빌드 다양성이 10종 기준보다 얕아진다. 완성도 작업 중 런 다양성이 부족하다고 판단되면, "새 마법 추가"가 아니라 **기존 5종의 강화·시너지 카드 폭을 넓히는 방향**으로 밸런스 트랙에서 보완한다(신규 마법은 여전히 2차).

**스코프 경계 (이번 전환에서 채택 — 사용자 확인 대기 기본값):**
- **성능 트랙(백로그 G1 — 공간 그리드 S2/S3, `maxEnemies` 캡 제거)** → **2차 이월.** 적을 더 안 늘리는 이상 현재 캡으로 성능이 안전하다. 완성도 작업 중 실제 프레임 드랍이 관측되면 재검토한다.
- **동결 경계** → 마법·적은 **버그·밸런스·현 기준 마감**만. 아직 미구현인 동작(적 없을 때 facing 방향 발사[백로그 A2], 마법 효과 잔여[A1: 빙결·호밍·체인·낙하·폭풍·빔])은 전부 2차.

> 위 두 경계는 사용자 부재(2026-07-02) 상황에서 저위험 기본값으로 채택했다. 완성도 영역(맵·스토리·플로우·UI)의 우선순위와 마일스톤(§10) 재시퀀싱은 다음 `/office-hours` 세션에서 확정한다.

## 1. 프로젝트 목표 (Goal)

**학습 + 출시 경험.** 사할을 걸거나 큰 자본 투자 없이, "부끄럽지 않은 작은 상업 게임을 출시하고 리뷰·구매를 받아본다"는 개인 학습 목표.

**성공 기준 (Definition of Success):**
- v1: itch.io 무료 출시까지 도달 + 5명 이상의 외부 플레이 기록
- v2: Steam 유료 출시까지 도달 + 평균 70% 이상 리뷰 점수 + 100카피 이상 판매
- 학습 측면: Cocos Creator 풀 사이클, AI 그래픽 파이프라인, Steam 출시 워크플로우 체득

## 2. 게임 컨셉 (One-Liner)

**"판타지 영웅이 한국 신화 세계에서 귀신과 싸우는 정통 덱 호드 서바이벌"**.

### 시나리오 (plan.md 원안 단순화)

```
한국 무당 + 일본 무녀 + 중국 스님의 합동 소환 의식
    ↓ 차원 균열
판타지 세계의 영웅들이 한국으로 강림
    ↓
한국 귀신/요괴들과의 전쟁 시작
    ↓
세계를 구원하면 다시 자기 세계로 귀환
```

캐릭터 해금 = 추가로 소환된 영웅들.

**장르 클러스터:** Vampire Survivors / Brotato / Hell Maiden / Magic Survival
**시점:** 탑다운 2D
**그래픽:** 고해상도 스타일라이즈드 2D — 애니 셀 화풍을 **유료 생성 서비스**(fal.ai Sandbox, 채택 모델 `openai/gpt-image-2`)로 뽑고, 플레이어와 해금 캐릭터는 **Spine** 스켈레탈 리깅으로 움직인다. 로컬 생성(ComfyUI + SDXL 1.0 base + 자체 스타일 LoRA)은 한 번 세웠다가 **2026-08-06에 폐기**했다 — 4방향을 뽑으려면 시점과 인물 동일성이 서로를 잡아먹어 뒷모습이 아예 나오지 않았고, 유료 쪽이 그 둘을 한 번에 통과했다. 화풍·해상도·파이프라인의 정본은 [`docs/design/art-direction.md`](../design/art-direction.md), 제작 규격은 [`docs/design/asset-production-spec.md`](../design/asset-production-spec.md), 생성 실행 절차는 [`docs/design/art-generation-playbook.md`](../design/art-generation-playbook.md)다.
