# art-drive — 드라이브로 올리는 아트 자료

> 레포에 올리지 않는 아트 자료는 어디에 어떤 구조로 두나

- **최초 작성:** 2026-09-19
- **드라이브 위치:** 아직 올리지 않았다. 올린 뒤 공유 폴더 주소를 이 줄에 적는다. 레포가 공개이므로 「링크가 있는 모든 사용자」가 아니라 **제한 공유**로 둔다

---

이 폴더는 **git이 추적하지 않는다.** `.gitignore`가 내용물을 통째로 막고 이 README 하나만 추적한다. 그래서 클론만 해서는 이 폴더가 비어 있고, 다른 장비에서는 드라이브에서 받아 **같은 경로에** 풀어야 도구가 입력을 찾는다.

레포 밖에 두는 이유는 둘이다. 생산 캐릭터 파일은 공개 레포에 올리면 누구나 내려받을 수 있고 한 번 푸시한 파일은 되돌릴 수 없다. 시험 자료는 main이 「검증이 끝난 최종 흐름과 코드」만 들게 하려는 것이다(2026-09-19 사용자 결정) — 무엇을 시험했고 어떻게 판정했는지는 세션 문서가 글과 수치로 들고, 그림은 다시 보고 싶을 때 여기서 연다.

`art-source/`와 헷갈리지 않는다. `art-source/`는 **출하한 아트의 최종 원본**을 git으로 추적하는 자리이고, 이 폴더는 추적하지 않는 자리다.

## 구조

```
art-drive/
├── README.md                          이 문서 (유일하게 추적된다)
├── production/                        굽기가 읽는 살아 있는 입력 — 잃으면 다시 만들 수 없다
│   └── player/
│       └── 2026-09-16-player-3d/      생산 .vrm 셋과 VRoid 원본
└── evidence/                          판정이 끝난 시험 자료 — 기록 보관용
    ├── player/
    │   ├── 2026-09-11-3d-gate/        1라운드: 시험용 .vrm · 비교 시트 · 모션 팩 · Cocos 테스트 씬
    │   └── 2026-09-17-3d-gate-round2-g2/   2라운드 G2 판정에 쓴 시트와 흉내
    └── enemies/
        └── 2026-09-17-ghost-samples/  화풍 비교용 귀신 표본 넷
```

폴더 이름은 `art-source/`와 같은 규칙(`<카테고리>/<날짜>-<주제>/`)을 따른다. 새 자료를 넣을 때 먼저 `production/`인지 `evidence/`인지를 가른다 — **도구가 지금도 읽는 입력이면 `production/`, 판정이 끝나 다시 읽을 일이 없으면 `evidence/`다.**

## production/ — 살아 있는 입력

| 폴더 | 파일 | 무엇 | 누가 읽나 |
|---|---|---|---|
| `player/2026-09-16-player-3d/` | `player_base.vrm` | 맨살 판(상의를 끈 것). 몸 층을 뽑고, 모든 층을 구울 때 가림 전용 몸으로 쓴다 | `tools/blender/probe_layers.py`의 `--base-vrm` |
| | `player_top_a.vrm` · `player_top_b.vrm` | 상의 A(흰 반팔티) · 상의 B(흰 배꼽 나시티)를 입힌 판. 상의 층을 머티리얼로 골라낸다 | 같은 도구의 `--top-vrm`, `inspect_meshes.py` |
| | `player_base.vroid` | VRoid Studio 원본. 세 `.vrm`을 다시 내보내거나 옷 · 얼굴을 고칠 때 연다 | 사람 |

이 셋은 G0이 공개 레포에 올리지 않기로 정한 파일이다(54MB). **여기서 지워지면 되찾을 길이 드라이브뿐이므로 드라이브에 올리기 전에는 이 폴더를 지우지 않는다.**

이 자료를 읽는 도구는 모두 `tools/blender/retired/`로 물러난 것들이다(`elevation.ts` · `mock.ts` · `sheet.ts` · `gate-round1.ts`). 어느 도구가 어느 파일을 읽는지는 [`tools/blender/retired/README.md`](../tools/blender/retired/README.md)가 든다. 그 도구들이 G4 뒤에 지워지면 이 자료는 입력 노릇이 끝나고 기록으로만 남는다.

## 문서에서 이 폴더를 가리킬 때

마크다운 링크나 그림 삽입으로 걸지 않고 `` `art-drive/evidence/...` ``처럼 **코드 표기로 경로만 적는다.** 링크 검사(`pnpm wf check-links`)가 git이 추적하는 파일 목록으로 판정하므로, 추적하지 않는 이 폴더를 링크하면 파일이 눈앞에 있어도 깨진 링크로 잡힌다. 드라이브에 올린 뒤의 공유 주소는 외부 주소라 검사 대상이 아니어서 링크로 걸어도 된다.
