# Monster

Cocos Creator로 만드는 개인 로그라이크 액션 게임.

## 어디를 보나

프로젝트의 규칙과 절차는 [`CLAUDE.md`](CLAUDE.md)가 든다. 그 문서의 라우팅 표가 질문 종류마다 어느 문서를 봐야 하는지를 가리킨다.

| 알고 싶은 것 | 문서 |
|---|---|
| 무엇을 만드는 게임인가 | [`docs/planning/`](docs/planning/) |
| 코드를 어떻게 쓰나 | [`docs/development/spec/code-conventions.md`](docs/development/spec/code-conventions.md) |
| 새 장비에 뭘 까나 | [`docs/development/spec/ops-environment.md`](docs/development/spec/ops-environment.md) |
| 지금 무슨 단계인가 | `pnpm wf status` |

문서 전체 구조는 `CLAUDE.md`의 「프로젝트 문서 구조」에 있다.
